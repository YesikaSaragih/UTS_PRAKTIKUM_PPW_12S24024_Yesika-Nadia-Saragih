# DEL Lab Equipment & Asset Tracking System - DEL-LEATS

Laboratorium Rekayasa Perangkat Lunak dan Jaringan di Institut Teknologi Del mengelola ratusan aset perangkat teknologi berharga tinggi (seperti laptop pengujian performa tinggi, drone observasi, kit sensor IoT, server mini, dan tablet digital). Selama ini, proses inventarisasi dan peminjaman perangkat laboratorium oleh mahasiswa untuk keperluan tugas akhir dan riset masih dilakukan secara manual menggunakan lembaran formulir fisik atau spreadsheet terpisah. Hal ini menimbulkan sejumlah kendala operasional yang serius: 

(1) Sering terjadi peminjaman ganda (double-booking) karena ketersediaan unit tidak termonitor secara real-time, 
(2) Riwayat kondisi fisik perangkat tidak terdokumentasi secara visual 
sehingga saat terjadi kerusakan tidak diketahui pihak yang bertanggung jawab, 
(3) Pengguna kesulitan mencari dan memfilter perangkat berdasarkan kategori spesifik karena data tidak terpaginasi dengan baik, dan 
(4) Formulir peminjaman kerap diisi dengan data asal-asalan tanpa penegakan validasi ketat sehingga batas pengembalian sering terlampaui tanpa perhitungan kompensasi yang jelas. 

Untuk memecahkan permasalahan di atas, saya merancang dan membangun modul inti 
aplikasi web terintegrasi berbasis pola arsitektur Model-View-Controller (MVC) yang menghubungkan 
antarmuka pengguna interaktif dengan penyimpanan basis data persisten.
